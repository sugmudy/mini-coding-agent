# Mini Coding Agent

A lightweight coding agent built from scratch for the NJU Software Engineering recommendation assessment.

The goal of this project is to build a minimal but complete coding agent that can interact with a large language model, operate on local files, execute commands, and iteratively complete programming tasks.

## Status

Under active development.

## Planned Core Features

- Read and inspect local project files
- Create and modify files
- Execute local shell commands
- Interact with an LLM through tool calling
- Maintain conversation and tool execution context
- Handle execution errors and agent termination

## Security

API keys and other credentials will be provided through environment variables or local configuration files excluded from version control.
